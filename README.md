# IslandBar

[Готовая сборка для Windows 11 x64](https://github.com/xoniksq/islandbar/releases/latest/download/IslandBar-Windows-x64.zip)

Распакуй архив в постоянную папку и запусти `IslandBar.exe`. Правый клик по часам открывает настройки островка. Там можно выбрать режим «Всегда раскрыт», включить запуск при входе и проверить обновления вручную.

Островок проверяет релизы на GitHub при запуске и в фоне. Подготовленное обновление устанавливается после минуты простоя ПК, когда хранилище закрыто и файловая очередь свободна. Настройки хранятся рядом с программой.

Пуш в `main` запускает Windows Release в GitHub Actions. Релиз содержит автономный ZIP и манифест с версией, размером и SHA-256. Номер сборки берётся из счётчика запусков workflow.

Локальная панель Windows: чёрный островок с часами внизу экрана. Нажатие раскрывает закреплённые приложения, открытые окна, язык ввода, быстрые настройки и часы. Выбор приложения, клик снаружи и Escape сворачивают панель.

Версия 1.5:

- Наведение на значок работающего приложения открывает живые миниатюры DWM (до четырёх окон). Нажатие выбирает окно; при уходе курсора миниатюры закрываются. Окна миниатюр освобождают регистрации DWM при закрытии.
- В звуковой карточке добавлен «Микшер приложений»: громкость и выключение звука отдельно для каждой программы со звуковой сессией. Изменения применяются к звуковым сессиям программы на активных устройствах.
- Иконки можно перетаскивать внутри панели. Правый клик также предлагает закрепить/открепить и переместить левее/правее. Настройки островка сохраняются в `dock-layout.json`, независимо от закреплений штатной панели Windows.
- Сетевой индикатор показывает загрузку и отдачу активного физического подключения. Служебные и фильтрующие интерфейсы исключены, чтобы не дублировать трафик. Это скорость текущих передач, а не тест пропускной способности провайдера.
- Наборы приложений: примеры «Игры», «Работа», «Музыка», редактор названия и состава, добавление программ/ярлыков. Открытые окна программ не запускаются повторно. Настройки — `app-sets.json`.
- `--convenience-check` проверяет сетевые счётчики, звуковые сессии с восстановлением громкости, сохранение закреплений и порядка, наборы и исключение уже открытых приложений.

Функции версии 1.4:

- Кнопка папки: системные Загрузки, Рабочий стол, Документы, Изображения, Видео и папка проектов. OneDrive учитывается через известные папки Windows. Можно добавлять свои каталоги; правый клик по своей папке убирает только ссылку.
- Кнопка загрузки: активные загрузки Яндекс Браузера, Chrome, Edge и Opera, полученный объём и процент при известном размере. Базы браузеров открываются только на чтение, URL не запрашиваются. Файлы `.crdownload` и `.part` дополнительно отслеживаются в папках загрузок. Когда размер неизвестен, отображается неопределённый прогресс; завершение показывает краткое уведомление. «Папка» открывает расположение файла, без его запуска.
- Кнопка мониторинга: текущая загрузка CPU в панели, карточка CPU/GPU с температурами, ОЗУ, видеопамятью и графиком за 45 секунд. Температуры читаются из существующей общей памяти MSI Afterburner, без установки драйвера. При отсутствии свежих датчиков показывается «Нет датчика»; загрузка CPU и память Windows продолжают работать.
- При перетаскивании файла наведение на свёрнутый островок раскрывает его. Удержание над значком запущенного приложения около 0,7 секунды выводит его окно вперёд. Файл нужно перенести в само окно: островок не принимает и не отправляет файлы.
- `--extras-check` проверяет загрузки на изолированной тестовой базе и временных файлах, обнаружение завершения, чтение без изменения базы, задержку наведения, папки и реальные датчики. Отчёт `extras-check.json`. `--extras-diagnostics` читает текущее состояние без создания тестовых файлов.

Функции версии 1.3:

- Карточка музыки в раскрытой панели: обложка, название и исполнитель. Нажатие открывает плеер с паузой, переключением и перемоткой. Яндекс.Музыка имеет приоритет среди медиасессий Windows. Смена трека ненадолго расширяет свёрнутый островок; при первом запуске уведомление не показывается.
- Кнопка динамика открывает собственную звуковую панель: общая громкость, выключение звука и выбор устройства вывода. Устройство связи сохраняется отдельно.
- Лупа или Ctrl+Alt+Пробел открывает поиск по приложениям меню «Пуск» и установленным приложениям Windows. Enter запускает выбранное, стрелки меняют выбор, Escape и клик снаружи закрывают поиск.
- Кнопка сетки предлагает выбор окон и четыре раскладки: две колонки, три колонки, четыре окна, главное окно с двумя боковыми. Окна перемещаются только после выбора раскладки. Учтены невидимые рамки Windows и место для островка.
- Оформление Graphite Blue: тёмные окна, голубой акцент и графитовый фон. Исходные значения хранятся в `appearance-before-island.json`; пункт «Вернуть прежнее оформление Windows» восстанавливает их. Если работает Wallpaper Engine, фон загружается через него, а прежние обои сохраняются в `wallpaper-engine-before-island.json`. Выход из островка возвращает штатную панель, сохраняя выбранное оформление.
- Новые карточки и контекстные меню закрываются кликом снаружи и Escape; повторное нажатие кнопки закрывает её карточку.

Проверка `--feature-check` проверяет громкость и медиакоманды с возвратом исходного состояния, индекс поиска, геометрию раскладок и перемещение временных скрытых тестовых окон. `--feature-diagnostics` читает состояние без переключения воспроизведения. Отчёт — `feature-check.json` рядом с исполняемым файлом.

- Закреплённые приложения читаются из пользовательской папки TaskBar. Открытые окна добавляются автоматически.
- Нажатие на работающую программу активирует её окно; повторное нажатие сворачивает активное окно. Правый клик по любому приложению открывает его собственное меню: запуск, выбор окна, сворачивание и обычный запрос закрытия окна. Меню островка открывается на фоне панели и часах.
- Shift+нажатие запускает новый экземпляр программы.
- Правая кнопка по островку открывает меню. В нём можно временно вернуть обычную панель, настроить автозапуск или выйти.
- Ctrl+Alt+B возвращает и раскрывает островок через ярлык рабочего стола «Включить островок» — сочетание доступно и после полного выхода из IslandBar. Escape сворачивает раскрытую панель.
- Ctrl+Alt+Shift+B восстанавливает обычную панель и завершает IslandBar.
- При закрытии или аварийном завершении процесса независимый процесс восстановления возвращает панель Windows.
- Версия 1.2.1: независимый запуск через задачу планировщика Windows `IslandBar` в интерактивном сеансе пользователя, без повышения прав. Задача запускается при входе, не имеет ограничения по длительности и работает от батареи. Переключатель автозапуска и `--restore` управляют этой задачей; прежняя запись Run удаляется.
- Системные файлы и параметры безопасности не меняются. Скрывается основное окно штатной панели; исходная видимость сохраняется в session.json.
- Стрелка вверх внутри раскрытого островка открывает штатные скрытые значки Windows над панелью. Повторное нажатие закрывает трей; Escape закрывает трей и сворачивает островок.
- В эксклюзивном полноэкранном режиме Direct3D, режиме презентации и при любом полноэкранном окне без рамки на переднем плане (игры borderless, полноэкранное видео) островок скрывается. Развёрнутые на весь экран обычные окна не считаются полноэкранными. Основное расположение — нижний край главного монитора.

Версия 1.2: крупные исходные значки приложений (256×256 или 48×48, в зависимости от ресурса программы), выравнивание по пикселям в покое и векторная стрелка скрытых значков трея. Штатная панель кратковременно показывается с нулевой прозрачностью для вызова её кнопки трея; исходные параметры сохраняются для восстановления при выходе или сбое. Постоянный размер окна, плавная анимация капсулы с сохранением скорости при повторном клике, обновление списка в фоне без пересоздания кнопок. Прозрачная область вокруг капсулы пропускает нажатия в приложение под ней.

`IslandBar.exe --preview` запускает проверку без скрытия панели Windows. `--restore` выключает автозапуск и возвращает штатную панель. `--diagnostics` записывает каталог приложений в diagnostics.json рядом с программой. Там же сохраняются log.txt, session.json и status.json.

Сборка: `dotnet publish IslandBar/IslandBar.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o <папка>`.
